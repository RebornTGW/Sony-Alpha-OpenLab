# Sony FX30 — profile

Sony APS-C (BIONZ XR) body profile for A6700-Remote-Tools. See `profile.json`
for USB VID/PID, interface class and capture handles.

Use from the repo root:
```bash
python cameras.py                 # list all bodies
python probe_a6700.py             # read-only diagnostic (auto-detect)
```

Original data only (MIT). No firmware content. Values marked `null` are to be
confirmed on hardware.
